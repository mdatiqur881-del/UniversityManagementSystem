# University Management System

**Second Semester Java Project**

A **console-based University Management System** developed in Java and designed for educational purposes. This project demonstrates core object-oriented programming concepts, file handling, exception handling, and data management in a real-world university scenario.

---

## Features

- **Student Management:** Add, manage, and track multiple students.  
- **Faculty Management:** Add, delete, view faculty, and assign advisors.  
- **Course Management:** Register and drop courses for each semester.  
- **Semester Handling:** Create multiple semesters and track courses for each semester.  
- **Academic Tracking:** Calculate GPA for each semester and cumulative CGPA.  
- **Transcript Generation:** Print and save transcripts to files.  
- **Advisor Assignment:** Assign faculty advisors to students.  
- **File Persistence:** Save and load student and faculty data using files (`students.dat`, `faculty.dat`).  
- **Exception Handling:** Handles invalid input and errors gracefully.  

---

## How to Run

1. Open the project in **NetBeans IDE**.  
2. Compile all `.java` files.  
3. Run the `Main.java` file.  
4. Follow the console instructions to manage students, faculty, courses, and semesters.
